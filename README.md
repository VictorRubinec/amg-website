## 🛠️ Tecnologias & Estrutura

- **HTML5 Semântico**: Arquitetura limpa com metadados completos de SEO, Open Graph e Twitter Cards.
- **CSS3 Moderno**: Design System *Luxury Dark Mode*, variáveis de tema, glassmorphism, animações contínuas (*ticker marquee*, pulso WhatsApp) e responsividade para todas as resoluções.
- **Vanilla JavaScript**: Interatividade leve com efeito *Text-Fill* no scroll, navegação âncora com rastreamento ativo, menu móvel e validação em tempo real de formulário.
- **Deploy**: Otimizado para **GitHub Pages** com `CNAME`, `robots.txt` e `sitemap.xml`.
